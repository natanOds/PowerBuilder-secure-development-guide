Nunca use CoSetProxyBlanket ou CoInitializeSecurity

Descrição da regra

  • As chamadas para as sub-rotinas CoSetProxyBlanket, CoInitializeSecurity e CoInitializeSecurityAlias ​​podem gerar violações de segurança. Encontrar essas chamadas no código do PowerBuilder para ajudar a removê-las.


Exemplo de código não compatível SUBROUTINE CoInitializeSecurityAlias(string uExitCode) LIBRARY "ole32.dll" ALIAS FOR "CoInitializeSecurity"

SUBROUTINE CoInitializeSecurity(string uExitCode) LIBRARY "ole32.dll"

SUBROUTINE CoSetProxyBlanket(string uExitCode) LIBRARY "ole32.dll"
