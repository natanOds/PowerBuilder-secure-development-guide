Os endereços IP não devem ser codificados

Descrição da regra

  • Codificar informações confidenciais, como endereços IP, chaves de criptografia ou senhas, pode expô-las a hackers. Se alguém puder acessar seus arquivos de tempo de execução, poderá descompilá-los e expor essas informações. O vazamento de informações protegidas por regulamentos oficiais como GDPR, SOX, HIPPA pode levar a grandes consequências legais.
  • Procurar qualquer endereço IP codificado para você remover essa violação de segurança.

String ls_ipv6

ls_ip = "127.0.0.1" // Código não compatível (Ip codificado)
ls_ipv6 = "2001:cdba:0:0:0:0:3257:9652" // Código não compatível (Ip codificado)
