As chaves de criptografia devem ser longas o suficiente

Descrição da regra

  • Para tornar as chaves criptográficas robustas contra ataques de força bruta, elas devem ter um tamanho de chave suficiente. Informar se as chaves não robustas são usadas em seu código do PowerBuilder.


Exemplo de código não compatível CrypterObject lnv_CrypterObject
lnv_CrypterObject = Create CrypterObject
// Gerar a chave
li_return = lnv_CrypterObject.AsymmetricGenerateKey(RSA!, 1024, lblb_privKey, lblb_pubKey) // Código não compatível (comprimento da chave < 2048)

Exemplo de código compatível CrypterObject lnv_CrypterObject
lnv_CrypterObject = Create CrypterObject
// Gerar a chave
li_return = lnv_CrypterObject.AsymmetricGenerateKey(RSA!, 2048, lblb_privKey, lblb_pubKey) //Código compatível (Comprimento da chave >= 2048, recomendação NIST)
