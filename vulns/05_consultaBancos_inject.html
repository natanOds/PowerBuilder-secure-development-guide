Consultas de banco de dados não devem ser vulneráveis ​​a ataques de injeção

Descrição da regra

  • A injeção de código é um ataque que injeta código malicioso que será interpretado/executado pelo aplicativo. Em particular, a injeção de código SQL permite realizar operações ilegais em seu banco de dados (acesso a dados confidenciais, aquisição ou desligamento do servidor…).
  • Por natureza, os aplicativos PowerBuilder são intensivos em banco de dados e de missão crítica.
  • Eles lidam com grandes volumes de dados importantes, o que os torna alvos privilegiados para hackers.
  • Procurar por concatenações de string, usadas para construir SQLs, e não são devidamente validadas ou escapadas. Eles podem criar grandes brechas para a injeção de SQL. Identificar e refatorar essas consultas fortalecerá a proteção do seu banco de dados.
