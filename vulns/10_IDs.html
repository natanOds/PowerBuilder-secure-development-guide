IDs de usuário e senhas não devem ser codificadas

Descrição da regra

  • Codificar informações confidenciais, como nomes de usuário ou senhas, endereços IP e chaves de criptografia, pode expô-los a hackers. Qualquer pessoa que acesse os arquivos executáveis ​​pode descompilá-los e encontrar as informações confidenciais. O vazamento de dados protegidos por regulamentações oficiais como GDPR, SOX, HIPPA pode gerar graves consequências legais.
  • Procurar IDs de usuário e senhas codificados, para permitir que você remova essas brechas de segurança.


Exemplo de código não compatível DBParm="ConnectString = 'DSN=Sales;UID=dba@123;PWD=sql1$12'" // Código não compatível (a senha é codificada)

SQLCA lnv_SQLCA
lnv_SQLCA = Create SQLCA
lnv_SQLCA.DBParm="ConnectString = 'DSN=Sales;UID=dba;PWD=sql'" // Código não compatível (a senha é codificada)

Exemplo de código compatível DBParm="ConnectString = 'DSN=Sales;UID=" + txtuserId.Text + ";PWD=" + txtPassword.Text + "'" //Código compatível
