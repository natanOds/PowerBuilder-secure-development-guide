Os comandos do sistema operacional não devem permitir ataques de injeção

Descrição da regra

  • Se seu código executa comandos do sistema operacional com base na entrada do usuário, ele deve verificar o nome de cada comando. Caso contrário, um hacker pode injetar seus próprios comandos para realizar operações ilegais e comprometer seu sistema.
  • Detectar essas falhas em seu código do PowerBuilder, para que você possa corrigi-las.
  • Por exemplo, você pode definir uma lista branca de comandos seguros e limpar os metacaracteres do shell.


Exemplo de código não compatível global function string callRun (string name)
Run(name)
Return name
end function

Exemplo de código compatível global function string callRun (string name)
Run("MYBATCH.BAT TEST")
Return name
end function
