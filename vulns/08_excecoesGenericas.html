Exceções genéricas não devem ser ignoradas

Descrição da regra

  • Em termos de tratamento de exceções, os blocos CATCH sempre devem ter um mecanismo de captura adequado. Identificar blocos catch vazios para proteger seu código com uma manipulação de exceção significativa.


Exemplo de código não compatível TRY
id = string (acos (ld_num1))
CATCH (runtimeerror er) // Código não compatível (bloco catch com apenas instrução return)
//Non compliant code (catch block with only return statement)
Return id
FINALLY
// Adicione o código de limpeza aqui
id = "id"
Return ""
END TRY

TRY
ls_valor = string (acos (ld_num))
CATCH (runtimeerror er) //Código não compatível (bloco catch sem instruções)
//MessageBox("Runtime Error", er.GetMessage()) //O código é comentado
FINALLY
// Adicione o código de limpeza aqui
ls_valor = "ls_valor"
Return ""
END TRY

Exemplo de código compatível TRY
id = string (acos (ld_num1))
CATCH (runtimeerror er)
// Código compatível
MessageBox("Runtime Error", er.GetMessage())
Return id
FINALLY
//Adicione o código de limpeza aqui
id = "id"
Return ""
END TRY
