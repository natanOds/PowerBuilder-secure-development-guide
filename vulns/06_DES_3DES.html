DES (Data Encryption Standard) ou 3DES não deve ser usado

Descrição da regra

  • O Data Encryption Standard (DES) é um algoritmo de chave simétrica para criptografar dados digitais. Seu comprimento de chave curto de 56 bits o torna inseguro. Não deve mais ser usado.
  • Encontrar todas as chamadas DES em seu código PowerBuilder, para que você possa removê-las.


Exemplo de código não compatível loo_Crypt = create oleobject
loo_Crypt.CryptAlgorithm = "des" //Não pode usar DES

CrypterObject lnv_CrypterObject
lnv_CrypterObject = Create CrypterObject
lblb_encrypt = lnv_CrypterObject.SymmetricEncrypt(DES!, lblb_data, lblb_key, &OperationModeCBC!, lblb_iv, PKCSPadding!) //Não pode usar DES
