Funções hash criptográficas não devem usar algoritmos SHA-1 ou Message-Digest

Descrição da regra

  • Os algoritmos SHA-1 e Message-Digest: os algoritmos MD2, MD4, MD5 e MD6 não são mais considerados seguros.


Exemplo de código não compatível global function string callMD5 (integer id)
Blob lblb_data
Blob lblb_md5
lblb_data = Blob("Test MD5", EncodingANSI!)

CrypterObject lnv_CrypterObject
lnv_CrypterObject = Create CrypterObject

// Criptografar com MD5
lblb_md5 = lnv_CrypterObject.MD5(lblb_data) //MD5 não é compatível

Return ""
end function

global function string testSHA (string text)

Blob lblb_data

Blob lblb_sha1
string ls_result

lblb_data = Blob(text, EncodingANSI!)

CrypterObject lnv_CrypterObject
lnv_CrypterObject = Create CrypterObject

// Criptografar com SHA
lblb_sha1= lnv_CrypterObject.SHA(SHA1!, lblb_data) //SHA1! não é compatível

ls_result = string(lblb_sha1, EncodingANSI!)

Return ls_result
end function

Exemplo de código compatível global function string testSHA (string text)

Blob lblb_data
Blob lblb_sha1
string ls_result

lblb_data = Blob(text, EncodingANSI!)

CrypterObject lnv_CrypterObject
lnv_CrypterObject = Create CrypterObject

// Criptografar com SHA
lblb_sha1= lnv_CrypterObject.SHA(SHA256!, lblb_data) //SHA256! é compatível

ls_result = string(lblb_sha1, EncodingANSI!)

Return ls_result
end function
